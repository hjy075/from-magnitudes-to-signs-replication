# From Magnitudes to Signs — Replication Package

Replication materials for:

**From Magnitudes to Signs: Joint Asymptotics of GMM under Repeated Second-Order Identification**

Author: **Jinyong Ha**  
Affiliation: Department of Data and Statistics, Graduate School of Policy Studies, Korea University  
Corresponding email: hjy075@korea.ac.kr

## Purpose

This repository contains the Monte Carlo code and saved summary outputs used in the manuscript. The simulations study a modified common-conditionally-heteroskedastic (common-CH) GMM design with two simultaneously second-order identified coordinates.

The repository supports three sets of numerical results:

1. quartic-root scaling and projected branch-score diagnostics;
2. feasible frozen two-step GMM versus oracle weighting;
3. feasible joint confidence-region calibration, including optimizer-boundary diagnostics.

No proprietary or external empirical data are used.

## Reproducing the manuscript results

### 1. Quartic-root scaling and projected branch scores

```bash
python scripts/common_ch_multidirectional_mc_projected.py \
  --replications 1000 \
  --burn 2000 \
  --seed 20260917 \
  --out results/common_ch_mc_projected_R1000_reproduced.csv
```

The manuscript's saved R=1000 output is:

```text
results/common_ch_mc_projected_R1000.csv
```

The separate large-n diagnostic saved from R=300 is:

```text
results/common_ch_mc_projected_largeN_R300.csv
```

### 2. Feasible frozen two-step versus oracle weighting

```bash
python scripts/common_ch_feasible_twostep.py \
  --replications 300 \
  --burn 2000 \
  --seed 20260917 \
  --out results/common_ch_feasible_twostep_R300_reproduced.csv
```

The manuscript's saved output is:

```text
results/common_ch_feasible_twostep_R300.csv
```

### 3. Joint confidence-region production run

Run:

```bash
python scripts/common_ch_joint_ci_final_fast.py \
  --replications 1000 \
  --burn 2000 \
  --seed 20260917 \
  --bsim 1500 \
  --out results/common_ch_joint_ci_R1000_raw_reproduced.csv
```

Then summarize it with:

```bash
python scripts/summarize_joint_ci.py \
  --input results/common_ch_joint_ci_R1000_raw_reproduced.csv \
  --output results/common_ch_joint_ci_R1000_summary_reproduced.csv
```

The manuscript's archived summary is:

```text
results/common_ch_joint_ci_R1000_summary.csv
```

## Main production audit

For the R=1000 joint-confidence experiment, the feasible 95% coverages reported in the final audit were approximately:

| n | Feasible coverage | Monte Carlo s.e. | Optimizer boundary hits |
|---:|---:|---:|---:|
| 2,000 | 0.910 | 0.009 | 0 / 1000 |
| 5,000 | 0.917 | 0.009 | 0 / 1000 |
| 10,000 | 0.914 | 0.009 | 0 / 1000 |

The paper therefore treats the feasible joint-inference result as an asymptotic consequence of the signed-law theory rather than as a claim of accurate moderate-sample calibration.

## Notes on numerical optimization

The final joint-CI production script uses a leading-image-based initializer plus fallback starts. This accelerated initializer was checked against the earlier broader multi-start implementation on hundreds of estimator cases: no sign mismatches were found and objective differences were at numerical precision.

The joint-CI script also records optimizer boundary hits. The final R=1000 run produced zero boundary hits at all three reported sample sizes.

## Reproducibility scope

This package is intended to reproduce the manuscript's Monte Carlo evidence. It does not contain an empirical dataset because the paper's numerical section is simulation-based.

The code is provided for scholarly replication of the manuscript.
